CSS Box Model – Theory & Live Demo

What is the Box Model?

The CSS Box Model describes how the size of an element is calculated and how it interacts with surrounding elements. Every element is represented as a rectangular box consisting of four regions (from the inside out):

  1. Content – the actual text, image, or other media.
  2. Padding – space between the content and the border.
  3. Border – a line that wraps the padding and content.
  4. Margin – the outermost space that separates the element from its neighbours.

Understanding the Box Model is essential for layout, spacing, and visual consistency.
